# Yandere Copy Generator | 病娇文案生成器

A browser-based Chinese yandere-style text generator powered by a local static corpus. No AI API, backend, or account required.

一个基于本地静态语料库的病娇风格中文文案生成器。无需 AI API、后端服务或账号登录，打开网页即可使用。

## Features | 功能

- **Custom Length | 自定义字数** — Set your desired output length.
- **Writing Themes | 文案主题** — Generate text around possessiveness, jealousy, obsession, emotional dependency, and dark monologues.
- **Live Character Count | 实时字数统计** — Track the generated text length.
- **One-Click Copy | 一键复制** — Copy the generated text to your clipboard.
- **Local Generation | 本地生成** — Uses a static corpus and rule-based text composition without external AI APIs.
- **No Backend Required | 无需后端** — Runs directly in a modern web browser.

## Usage | 使用方法

1. Open the generator in your browser.
2. Enter your desired target length.
3. Choose a writing theme, if available.
4. Click the generate button.
5. Copy the result when you're satisfied with the output.

1. 在浏览器中打开生成器。
2. 输入目标字数。
3. 根据需要选择文案主题。
4. 点击生成按钮。
5. 满意后复制生成的文案。

## Deployment | 部署

This project is a static website and can be hosted with GitHub Pages.

本项目为静态网页，可通过 GitHub Pages 部署。

1. Upload `index.html` to the root directory of this repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Click **Save** and wait for deployment to finish.

部署步骤：

1. 将 `index.html` 上传到仓库根目录。
2. 打开 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)` 目录。
5. 点击 **Save**，等待部署完成。

## Privacy | 隐私

Text generation runs in the browser using the bundled corpus. No external AI API is required.

文案生成在浏览器本地完成，使用网页内置语料，不需要调用外部 AI API。

## Limitations | 局限性

Output quality depends on the size, diversity, and organization of the local corpus and the composition rules. Repeated patterns may occur.

生成效果取决于本地语料的规模、多样性及组合规则。语料不足或句式相似时，仍可能出现重复内容。
